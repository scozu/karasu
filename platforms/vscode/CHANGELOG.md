# Changelog

All notable changes to the `karasu-theme` extension are documented here.

## 0.2.0

- Refactored VS Code theme generation into `platforms/vscode/spec.mjs`.
- Expanded workbench color coverage to 190 keys per variant.
- Added semantic highlighting support and semantic token colors.
- Expanded TextMate token rules to 82 entries.
- Added extension packaging metadata for marketplace readiness.
- Added dedicated VS Code validation script: `scripts/check-vscode-theme.mjs`.
- Added preview assets, icon, and a marketplace-focused extension README.
- Added CI and release workflows for packaging + publishing.

## 0.1.0

- Initial VS Code package with Karasu Night and Karasu Snow themes.
